# Overmind task backlog

Only task descriptions live here; nothing is built. Start with `CONVENTIONS.md`, then `PLAN.md`.

- `OVE_<AREA><NNN>/TASK.md`: one small, fully specified task (front matter + 14 sections). `design.png` is the crop of the design this task implements; no image means a functionality-only task.
- `INDEX.md`, `DEPENDENCIES.md`: generated overview and dependency graph.
- `UNRESOLVED.md`: capabilities still without an owner, duplicate providers and skipped cycle edges. Resolve before starting the affected tasks.
- `_design/`: full 2x views, HTML sources, `VIEWS.md` (regions) and `COMPONENT-INVENTORY.md`.
- `_proposals/`: change requests between tasks. `_template/`: task template and author brief.
