# Domyślna lista akcji wymagających Zgody

Domyślnie Zgody Właściciela wymagają: usuwanie plików, `git push` i każda publikacja, wysyłanie wiadomości lub maili na zewnątrz, płatności, wejście na nową domenę w internecie oraz przekroczenie Budżetu. Wszystko inne Agenci robią sami. Właściciel może w Regułach Właściciela zdjąć wymóg Zgody z wybranej akcji, np. pozwolić Agentowi samodzielnie wypychać zmiany.

## Konsekwencje

- Zdjęcie wymogu Zgody rozszerza uprawnienia, więc jest możliwe tylko lokalnie, nigdy z Telegrama (ADR 0003).
