# Kod, repozytorium i dokumentacja po angielsku

Overmind jest open source i ma przyciągać kontrybutorów z całego świata, więc kod, repozytorium, dokumentacja i domyślny interfejs są po angielsku. Polski jest pierwszym tłumaczeniem interfejsu. Obecna dokumentacja projektowa, pisana po polsku, zostanie przetłumaczona przed publikacją repozytorium, a słownik dostanie nazwy w obu językach.
